# MuPad 0.3 — Learn Python

MuPad now focuses on learning Python, with desktop editions alongside the iPad app.

## What's new

- Windows x64 installer, Linux x64 Debian package and AppImage.
- Six courses and 36 original lessons: beginner, intermediate and advanced.
- Each lesson has an explanation, runnable example, coding task, two progressive hints and a solution you can reveal intentionally.
- Check solution executes real Python assertions. Errors, an unfinished task and an early sys.exit do not earn completion.
- Local learning progress, separate exercise files, and a guide to first runs, input, errors and backups.
- Helpful tips alongside the original Python tracebacks.
- Full-screen console with live input, EOF, Run/Stop and a return-to-editor button. It also works without the native browser fullscreen API.
- Original MuPad app icon and learning-focused repository description/banner.

## Downloads and installation

Choose the Windows `.exe`, Linux `.deb` / `.AppImage`, or iPad `.ipa` under Assets. Desktop builds target x64. An AppImage must be executable and needs compatible Linux/FUSE/sandbox support; use the Debian package on Ubuntu if the portable build cannot use the host sandbox. The app never deliberately disables Chromium's sandbox.

Packages are unsigned. Verify SHA256SUMS.txt before installation. The IPA needs signing through your own sideloading setup; it is not an App Store/TestFlight build. Windows can show an unknown-publisher warning. Do not disable your system's security protections.

Export important scripts before replacing an existing installation. Editor drafts and course progress stay local; progress does not sync between devices. Files created by Python itself are still temporary between runs. Courses/guides are in English.

## Verification

Every curriculum solution/check is executed by the bundled CPython interpreter. CI additionally exercises the built and installed Windows/Debian applications and the iPad-simulator WKWebView. Source and build references are recorded in the published release body.
