# MuPad 0.2

The first public release of MuPad, a small Python editor for iPad.

Write normal Python, open and export `.py` files, and run your scripts locally. The interpreter and standard library are bundled with the app, so running ordinary scripts works offline.

This version includes syntax highlighting, saved drafts, workspace imports, live output and tracebacks, native prompts for ordinary `input()`, and a Stop button that can terminate an infinite loop.

## Download and install

Download **MuPad-0.2-unsigned.ipa** from the assets below. It is an unsigned ARM64 iOS app and needs a valid signature through your sideloading setup before installation. It is not an App Store or TestFlight download. The minimum deployment target is iOS/iPadOS 17.

Export important scripts before replacing an existing installation.

## Limits worth knowing

Each run starts a fresh interpreter. Editor files persist, but files created by a running script are currently temporary. Desktop GUI libraries, hardware-specific modules, and arbitrary native Python packages aren't supported. See the README for details.
