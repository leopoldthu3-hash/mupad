    Your first steps with MuPad
    

    You do not need to install Python separately. Your code runs on this device, even offline. Start small, change something, and run it again.
    

      

    1. Write your first line
      Tap the editor and try this ordinary Python program. Quotes tell Python that the words are text.
      print("Hello, MuPad!")
      2. 

    2. Press Run and read the console
      Run starts your program. The console underneath shows what it prints. Change the words and run again. Expand console makes this area fill the app; Collapse console or Escape brings the editor back.
      3. 

    3. Ask for input
      name = input("Your name: ")
print("Hello", name)
      On iPad, answer the native prompt. On Windows/Linux, type in the input box and press Send. Blank input is allowed. EOF means there is no more input; it is different from sending an empty line. Optional program input supplies one line for each input() call.
      4. 

    4. Learn by doing
      Open Learn, start with the first course, read the example, and Load exercise. Each task opens a new file, leaving your drafts alone. Run lets you experiment; Check solution tests your answer using real Python. Try the next hint before revealing the example solution. Your completed tasks stay on this device.
      5. 

    5. Use Stop when you need it
      If a loop keeps running, press Stop. The editor stays usable and you can fix the code and Run again. Each run starts fresh, so rerun the whole program after changes.
      6. 

    6. Make mistakes safely
      Errors are part of learning. Look at the filename and line number in the traceback. MuPad adds a short tip for common mistakes. Check quotes, spelling and the four-space indentation inside if, for and def blocks. Use Indent/Outdent and Undo when needed.
      7. 

    7. Keep your work
      New makes a .py file; Open .py imports one; rename and switch files in the sidebar. Drafts save automatically inside MuPad. Export .py saves a separate backup to your files/downloads (or the iPad share sheet). Export important work before uninstalling or replacing the app. Files written by a Python program itself are temporary between runs.
      8. 

    8. What next?
      Try a greeting, a small calculator, a quiz, or a guessing game. Work from first steps through decisions, loops, collections, functions, files and advanced projects. The ordinary Python editor stays available outside lessons.
      9.
